# StopWatch 目玉表示 — 基本設計

## 目的と範囲

M5Stack StopWatch の丸い画面に目玉をひとつ表示し、眺めて楽しめる道具にする。本体そのものが一匹の生き物に感じられる表現を目指す。

今回扱うのは、目の表示、視線移動、まばたき、見た目の切り替えのみ。音声、通信、外部サービス・PC 連携、LLM、傾きやタッチへの反応は含めない。以前の連携案は、今回の設計の前提にも将来要件にも置かない。

この文書は基本設計であり、実装計画やファームウェア書き込みの承認ではない。

## 表示と振る舞い

- 丸い画面いっぱいに目をひとつ表示する。顔全体や、画面内を歩くキャラクターは描かない。
- 操作しなくても視線が動き、ときどきまばたきをする。
- 視線が止まる時間を設け、動き続ける機械的な印象を避ける。
- 人の位置を認識する機能は持たない。「目が合う」感覚は、視線の動きによる演出とする。
- リアル風と目玉親父風の2種類を切り替えられる。

| 見た目 | 表現の方向 |
| --- | --- |
| リアル風 | 虹彩の模様、柔らかな陰影、光の映り込みで眼球の質感を出す。過度に生々しい表現は避ける。 |
| 目玉親父風 | 白目とシンプルな黒目を中心とする、漫画的で親しみやすい表現。 |

リアル風だけでは不気味に感じる可能性があるため、どちらか一方に固定せず切り替えられるようにする。切り替えに本体ボタンを使う案はあるが、操作方法は未確定。

## 設計の要点

目の動きと、その描き方を分ける。視線とまぶたの開き具合を共通の状態として扱い、選択中の見た目で画面に描く。

```text
時間の経過 → 視線・まばたきの状態を更新
                        ↓
見た目の選択 ───→ 選択中の描き方で表示 → 本体の画面
```

2種類のために動きの仕組みを別々に作らず、同じ動きを異なる見た目で楽しめる構成とする。具体的なコード構成や描画方式は、この文書では定めない。

既存プロジェクトの機能を拡張する設計ではなく、新規開発として扱う。開発言語・ツール・ライブラリは未選定であり、Arduino、PlatformIO、TinyGo などの採用は決定していない。

## 後続で決めることと未検証事項

| 項目 | 現在地と次の判断 |
| --- | --- |
| 開発環境・描画方式 | 未選定。StopWatch の画面対応とアニメーションの実現性を確認し、後続の Planning で選ぶ。 |
| 切り替え操作・起動時の見た目 | 未確定。表示機能の範囲内で後から決められるため、後続で具体化する。設定の永続化は現時点の要件に含めない。 |
| 視線の範囲・速さ・停止時間、まばたきの間隔 | 数値は未確定。実際の動きを見て、生き物らしく感じる間合いに調整する。 |
| 色・模様・陰影の強さ | 詳細は未確定。リアル風の不気味さと、漫画風の親しみやすさを実画面で比較する。 |
| 描画性能 | 未検証。実機で、視線移動やまばたきが見苦しく途切れないか確認する。 |

見た目と動きの細部は、文章だけで固定するより実画面で比較する方が目的に合うため、試作時の調整に委ねる。機能追加のための保留ではない。

目的を満たすかは、ひとつの目として自然に見えること、動きと静止の間合いを楽しめること、2種類の見た目を切り替えられることを中心に判断する。
